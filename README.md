# Cztery działania

Aplikacja do ćwiczenia dodawania, odejmowania, mnożenia i dzielenia dla 11-latka.

- 10 losowych zadań na liczbach do 99, trzy poziomy trudności: łatwy, średni, trudny
- naklejki do wyboru: corgi, aksolotl albo kot, jedna za każdą dobrą odpowiedź
- puchar Super Corgi, Super Aksolotl lub Super Kot za 10/10, osobny dla każdego poziomu (9 do zdobycia)
- po zdobyciu pucharu krótki animowany filmik-nagroda
- raport na końcu: wynik, lista zadań i błędne odpowiedzi

To jeden plik `index.html`, bez instalacji. Wystarczy otworzyć go w przeglądarce albo włączyć GitHub Pages dla tego repozytorium.
Zdobyte puchary zapisują się w przeglądarce, na której gra dziecko.
